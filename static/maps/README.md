# 2.5D 맵 넣는 법

## 0) 시점 — 제일 먼저 맞출 것

**뒤에서 본 시점으로 그린다. 옆에서 본 그림은 쓸 수 없다.**

이 게임의 카메라는 라이더 **뒤**(3인칭) 아니면 라이더의 **눈**(1인칭)이다. 캐릭터
스프라이트도 뒷모습이고, 콕핏은 내 핸들바를 내려다본 그림이다. 그래서 배경도
**앞으로 달려나가는 시점**이어야 한다:

- 길은 화면 **아래에서 위(소실점)로** 뻗는다. 가로로 누운 길이 아니다.
- 노면 글자·차선은 **멀어질수록 좁아지고 짧아진다**. 가로로 반복되면 안 된다.
- 가로수·벤치·난간은 길 **양옆에 늘어서서 소실점으로 모인다**. 정면 입면도가 아니다.

한강 맵(`hanriver`)이 이 함정에 빠졌다 — 옆에서 본 횡스크롤 배경이라 뒷모습
라이더를 얹으면 길과 90도로 어긋난 채 달리는 그림이 된다. 아트는 훌륭한데 시점이
다르다. 옆모습 배경을 쓰려면 캐릭터·콕핏·라이벌 투영까지 전부 옆모습으로 바꿔야 한다.

맵 하나 = 폴더 하나.

```
static/maps/
├── index.json          ← 메뉴에 나올 목록
└── coastal/
    ├── map.json        ← 이 맵의 정의
    ├── sky.png         ← 레이어 그림 (없으면 대체 그림이 들어간다)
    ├── far.png
    ├── mid.png
    ├── near.png
    └── road.png
```

## 1) 그림

**좌우 끝이 이어지게.** 왼쪽 끝과 오른쪽 끝을 붙였을 때 경계가 보이면 달리는 내내
그 줄이 주기적으로 지나간다. "이어지게 만들었다"는 말만 믿지 말고 실제로 재볼 것 —
한강 맵은 seamless라고 받았지만 좌우 끝 평균 색차가 near 62/255, mid 35/255였다.
`layer4_near`는 화면에 1.3초에 한 번씩 이음매가 지나간다.

**위아래 끝은 직선으로 자르지 말 것.** 반투명 레이어의 내용을 가로 직선으로 잘라내면
그 선이 하늘에 자처럼 그어진다. 한강 맵의 `near`는 y=318에서, `mid`는 y=422에서
알파가 4픽셀 만에 0→255로 튀어 버드나무 가지가 썰려 있다. 내용의 윤곽을 따라
자르거나, 최소한 수십 픽셀에 걸쳐 흐려지게 할 것.

**초록 배경으로 키잉했으면 가장자리 초록을 뺄 것.** 안 빼면 나무·벤치 둘레에 초록
테두리가 보인다 (`tools\despill.py`가 반투명 픽셀만 골라 뺀다 — 진짜 초록은 남긴다).

| 레이어 | 무엇 | 배경 | 화면에서의 높이 |
|--------|------|------|----------------|
| `sky`  | 하늘·구름 | 불투명 | 화면 위 62% |
| `far`  | 산·바다·먼 스카이라인 | **투명** | 아래끝이 지평선, 높이 30% |
| `mid`  | 건물·나무 | **투명** | 아래끝이 지평선, 높이 26% |
| `near` | 가드레일·표지판·전봇대 | **투명** | 아래끝이 지평선, 높이 17% |
| `road` | 노면 | 불투명 | 지평선에서 화면 아래까지 |

sky와 road 말고는 **알파가 있어야** 뒤 레이어가 비친다. 체크무늬를 픽셀로 그려주는
생성기가 많으니 `tools\sprite_alpha.py`로 진짜 알파로 바꿔서 넣을 것.

## 2) map.json

```json
{
  "name": "해안도로",
  "layers": {
    "sky": "maps/coastal/sky.png",
    "far": "maps/coastal/far.png",
    "mid": "maps/coastal/mid.png",
    "near": "maps/coastal/near.png",
    "road": "maps/coastal/road.png"
  },
  "scrollSpeed": { "sky": 0.02, "far": 0.1, "mid": 0.4, "near": 0.8, "road": 1.0 }
}
```

레이어를 화면 전체 한 장으로 합성해서 줄 때는 이 모양도 그대로 읽는다 (받은 meta를
손으로 옮겨 적지 않아도 된다):

```json
"layers": { "sky": { "file": "layer1_sky.jpg", "speed": 0.02, "position": "full" } }
```

`position`은 `"bottom"`(노면으로 꽉 찬 한 장 → 지평선 아래 띠로 눌러 넣는다)만 다르게
읽고, 나머지는 전부 화면 전체로 본다. 이때는 지평선이 그림에 그려져 있으므로 맵에
`"horizon"`(0~1)도 같이 줘야 라이벌·코인이 그림 속 길과 같은 높이에 선다.

`layers`의 경로는 `/static/` 기준이다 (`file`로 줄 때는 맵 폴더 기준 파일명). 선택 항목:

- `pxPerM` — 1m 달릴 때 도로가 움직이는 픽셀 (기본 14). 너무 빠르면 뭉개지고 느리면 안 달리는 것 같다.
- `layout` — 레이어별 `{ "anchor": "top"|"horizon"|"horizonTop", "height": 0~1 }`로 위 표를 덮어쓴다.
- `roadMode` — `"toward"`로 두면 도로를 가로가 아니라 **세로로** 흘린다 (위에서 내려다본 노면 그림용).
- `placeholder` — 그림이 없을 때 쓸 대체 색 `{ sky:[3색], far, mid, near, road, lane }`.

## 3) index.json에 한 줄

```json
[{ "id": "coastal", "name": "해안도로" }]
```

여기 들어간 것만 메뉴의 맵 고르는 줄에 나온다.
